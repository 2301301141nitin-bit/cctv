# CCTV SOC Dashboard

This is a production-ready Security Operations Center (SOC) dashboard built with Next.js, Tailwind CSS, and Firebase. It provides a real-time interface for monitoring CCTV alerts generated by local inference nodes.

## Prerequisites
- Node.js 18+
- A Firebase project with Firestore and Authentication enabled.

## Local Development

1.  **Configure Environment Variables**
    Copy `.env.local` (or use the template below) and fill in your Firebase configuration values. You can find these in your Firebase Project Settings under "Web App".

    ```env
    NEXT_PUBLIC_FIREBASE_API_KEY=your_api_key
    NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=your_project_id.firebaseapp.com
    NEXT_PUBLIC_FIREBASE_PROJECT_ID=your_project_id
    NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=your_project_id.appspot.com
    NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=your_messaging_sender_id
    NEXT_PUBLIC_FIREBASE_APP_ID=your_app_id
    ```

2.  **Install Dependencies**
    ```bash
    npm install
    ```

3.  **Run Development Server**
    ```bash
    npm run dev
    ```
    Open [http://localhost:3000](http://localhost:3000) in your browser.

## Deployment to Vercel

The easiest way to deploy this dashboard to production is via Vercel.

1.  Push your code to a GitHub, GitLab, or Bitbucket repository.
2.  Log in to [Vercel](https://vercel.com/) and create a **New Project**.
3.  Import the repository and select the `soc_dashboard` directory as the Root Directory if it's part of a monorepo.
4.  Expand the **Environment Variables** section and add all your `NEXT_PUBLIC_FIREBASE_*` keys.
5.  Click **Deploy**.

Vercel will automatically build the Next.js application and assign it a live URL.

## Firebase Security Rules (Firestore)

To secure your production database, ensure your Firestore rules restrict access to authenticated operators only. Example rules:

```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // Only authenticated users can read/write nodes and events
    match /nodes/{document=**} {
      allow read, write: if request.auth != null;
    }
    match /events/{document=**} {
      allow read, write: if request.auth != null;
    }
  }
}
```
